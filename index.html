How the testing works

Same paper, every model

Every model sits the same fixed set of corporate and transactional questions, so results compare like for like, release after release.

Marked by a lawyer

Answers are marked against what a corporate lawyer in India would actually expect to see in a real transaction, not against a generic rubric.

Answers on the record

Every review publishes the prompt, the answer extract and the marker's note, so you can check the mark yourself.
